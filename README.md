# Coin Flip Game

## Project Description

Coin Flip Game is a simple Python program that simulates flipping a coin. The user can flip the coin as many times as they want and the program keeps track of the number of Heads and Tails.

The game uses Python's `random` module to randomly generate Heads or Tails.

## Features

- Flip the coin multiple times
- Count total Heads
- Count total Tails
- Display the total number of flips
- Show the final result
- Quit the game whenever needed

## Concepts Used

- Variables
- `while` loop
- `if`, `elif`, and `else`
- User input
- `random.randint()`
- Counters
- Basic arithmetic

## Requirements

- Python 3.x
- No external libraries are required

## How to Run

1. Install Python 3 if it is not already installed.
2. Save the program as `coin_flip.py`.
3. Open Terminal or Command Prompt in the project folder.
4. Run:

```bash
python3 coin_flip.py
```

On some systems, you can also use:

```bash
python coin_flip.py
```

## How to Play

- Press **Enter** to flip the coin.
- Type **q** and press Enter to stop the game.
- After every flip, the current number of Heads, Tails, and total flips is displayed.
- At the end, the program shows the final result.

## Project Output

The program displays whether the coin landed on Heads or Tails after every flip and gives a final count when the game ends.
